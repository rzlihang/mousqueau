# Known limitations and v0.2

- macOS native dialogs, playback/codecs, launch environment, app bundling, and signing/notarization require verification on a real Mac. Linux server-mode checks do not establish that GUI behavior. Windows/Linux desktop builds have portable scaffolding but are not GUI-tested here.
- This environment has no OpenAI credential and no allowed OpenAI/YouTube destinations. Live transcription and live YouTube discovery/download were not performed. Multipart requests and response handling use local HTTP fixtures; the demo uses mock segments. Endpoint/model availability, billing, provider transcription quality, and video availability remain external dependencies.
- The UI/examples preserve Traditional Chinese and support Chinese transcription. `language=zh` cannot force Traditional Chinese or Taiwanese orthography. No prompt is sent to the diarization model; no automatic script conversion or stylistic rewriting is applied.
- Whole transcription segments cannot be reliably split into words for several SRT cues. Boundary-crossing suggestions therefore need manual review. A multi-speaker cue retains multiple annotations; it is not automatically split into new cues. Nearby subtitle wording remains visible for human context; v0.1 does not make an extra text-correction model call using that context.
- Different requests do not recognize the same person automatically. Users can rename/map speakers manually; known-speaker voice references are left behind a provider extension boundary.
- SRT import supports UTF-8 (including BOM), standard numeric cue identifiers, multiline text, and comma/dot millisecond timestamps. Legacy encodings, ASS styling, SRT positioning extensions, and direct local VTT editing are not supported. Use yt-dlp/FFmpeg conversion for supported remote VTT tracks.
- Playback depends on native WebView codecs. Remux/transcode unsupported media separately. Editing is still available when media cannot play.
- Projects retain local absolute media paths and up to 100 undo snapshots. There is no autosave or external-file watcher; save before replacing a project or exiting. Native window-close warnings may vary by WebView. Every save/export requires a new filename.
- yt-dlp downloads may require current JavaScript/EJS dependencies. Restricted/private videos, browser cookies, logins, full episodes, playlists, channels, local speech models, accounts, and cloud synchronization are excluded. No external CLI binaries are bundled.
- The official template's icons are retained; signing identities and installer branding are not release-ready. The native Mac template uses ad-hoc signing, but release signing/notarization is not configured.

Suggested v0.2: delta-based history/autosave, non-destructive project updates with original-file protection, waveform and subtitle splitting, compact word-boundary alignment, tested Traditional Chinese orthography assistance, user-controlled known-speaker references, secure OS keychain configuration, native codec/platform testing, accessible keyboard navigation, and signed/notarized installers.
